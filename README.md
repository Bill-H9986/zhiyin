# 知音 · AI 内容创作与多平台营销系统

知音是一个面向零基础用户的 AI 内容创作与多平台营销助手，集成 **AI 文案/图片/视频生成、多平台发布、7×24 客户接待、数据与作品管理**，下载安装后即可直接使用，无需配置数据库或环境变量。

## 功能亮点

- **AI 内容创作**：输入一句需求，自动生成文案、图片和视频草稿，支持多轮续写。
- **多平台发布**：支持抖音、小红书、视频号等多平台，素材与发布任务集中管理。
- **客户接待**：评论和私信统一处理，自动接待与人工介入随时切换。
- **数据与作品管理**：作品、任务、发布记录本地留档，随时回看。
- **本地安全**：平台账号与本地数据保存在你的电脑，不依赖额外服务器。
- **自动更新**：首次安装后，后续版本在 APP 内自动检测并更新。

## 获取安装

- 打开 [官方下载页](https://bill-h9986.github.io/zhiyin/)，点击 **下载知音**。
- 或直接前往 [最新 Release](https://github.com/Bill-H9986/zhiyin/releases/latest) 下载安装包。
- 系统要求：**Windows 10 / 11**。
- 安装包已包含本地运行所需组件（MongoDB / Redis / MinIO / Node 后端均已内置）。
- 若 Windows 提示“已保护你的电脑”，请点击 **更多信息 → 仍要运行**。

## 自动更新

首次安装完成后，后续版本将在 APP 内自动检测并下载更新，无需手动重新安装。

## 仓库结构

本仓库为 **公开的下载与发布页仓库**，不包含源码与密钥：

- `docs/`：下载页面及示例素材（顶部 Logo、精选示例视频等）
- `.github/workflows/deploy-download-page.yml`：GitHub Pages 自动部署
- `Releases`：Windows 安装包 `zhiyin-latest.exe`、OTA 增量包 `latest.yml / update.json`

> 完整源码与后端资源保存在私有仓库，仅用于自动构建，不在此公开，因此公开仓库不包含任何真实 Cookie / 密钥 / 账号凭据。

## 开发者 / 构建说明

- 前后端为 Nx + pnpm 多包工作区；桌面端为 Electron + Vite。
- 下载页推送 `docs/**` 即触发 GitHub Actions 自动部署。
- 新版本由私有 CI 构建后自动上传安装包与 OTA 元数据到本仓库。
